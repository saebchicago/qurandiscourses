How to read this

  • Text filters match a piece of the cell. Arabic vowel marks and case are ignored, so plain letters find a pointed word.
  • Number filters take >=2, <0.5, =3, 5..10 or a bare number. A row with no value never matches a filter on that column.
  • The tables are the published ones, with the counting rules, method and verification label for each given in the schema on Export. Rows with an empty cell mean the value is not available, not zero.
  • Counts of downloads from Export are the only analytics on this page: which table and format, nothing you filter or type.
